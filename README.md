# 超维网络（HyperdimensionalNetwork）

超维网络是一个给《七日杀》用的随身仓库。东西存进网络后，平时做东西、修装备、给载具加油时都能直接用，不用先从仓库拿出来。单人可以用，多人也可以邀请朋友共用一个网络；库存和权限由服务器管理。

## 能做什么

- **随身存取物品**：网络界面可以搜索、分类和翻页，也支持拖放、整组取放和半组取放。背包、快捷栏和当前打开的箱子、掉落袋、载具等都能快速存入。
- **直接使用网络材料**：制作、给工作站供料、维修装备、修理或升级建筑，以及给载具加油和维修时，都可以使用网络里的材料。
- **给附近锻造炉补料**：在锻造炉的熔炼材料区域打开补料面板，选择要投料的锻造炉和材料，再设置每座炉的目标量。默认只选当前打开的锻造炉，也可以全选或反选；选中的炉会在游戏画面中显示标记。先用背包未锁定格里的材料，不够再从网络取。目标量填 `0` 表示补到上限。
- **补货和弹药**：把快捷栏或背包里已有的物品堆叠补满，也可以设置自动补货范围。远程武器换弹时能使用网络弹药；管理员可以在设置中开关相关功能。
- **链式合成**：从已追踪的配方开始规划材料和制作步骤，再交给原版制作队列或可用工作站执行；可以在网络界面查看订单进度。
- **商人买卖**：手动卖出物品，也可以汇总已发现商人的商品来购买。管理员能设置自动买入和卖出规则。
- **自动整理和销毁**：可以按规则自动存入、卖出或销毁物品。背包处理顺序是先卖出，再销毁，最后存入；管理员管理网络级买卖和销毁规则，个人存入及个人垃圾桶规则由每位玩家自己保存。
- **垃圾桶**：使用背包上方的垃圾桶按钮打开原版容器窗口。可以拖入物品，也可以按住 `Shift` 并左键点击背包物品快速放入。关掉窗口时，桶里剩下的东西会被销毁。容量会随背包格数调整，最多 500 格。
- **自动读书和处理书籍**：可以自动阅读背包里的未读书。已读书可以选择卖掉、按原版方式分解或继续阅读；网络里的书也能批量阅读、出售或分解。
- **和朋友共用网络**：可以邀请玩家加入、管理成员、踢出成员、退出网络或转让管理员。每位玩家的权限和网络库存由服务器确认。

## 安装

把 `HyperdimensionalNetwork` 文件夹放进游戏的 `Mods` 文件夹，例如：

```text
7 Days To Die/Mods/HyperdimensionalNetwork
```

多人游戏时，主机或服务器和所有客户端都要安装同一版本。

## 常用操作

### 打开网络和存取物品

- 进入存档后，点击导航栏左侧的书本图标，或按 `O` 打开网络窗口。
- 左键从网络取出一组，右键取出半组；在背包里按住 `Shift` 再右键可存入半组，在网络里这样操作可取出半组。
- 打开箱子、掉落袋、载具或无人机等物品窗口时按 `D`，可以把**当前窗口**里的物品存入网络。这个按键只处理当前打开的窗口，不会搜索附近的箱子。

### 补货、自动化和设置

- 在网络设置里，“个人设置”由自己调整；“管理员设置”只对网络管理员开放。管理员可以开关网络的补货、弹药、商人、链式合成、存入、垃圾桶和读书功能。
- 在“自动化设置”里添加规则，也可以立即执行。个人存入和个人垃圾桶规则各自保存；自动买卖和网络销毁规则由管理员管理。
- 补货会填充快捷栏或背包中已有的堆叠，不会在空格里凭空新建一组。自动补货的监测范围可以在个人设置中调整。

### 锻造炉补料

打开锻造炉后，在熔炼材料区域点击炉子按钮。面板会列出 15 米内最多 8 座可访问的锻造炉，默认只选当前这座；左键点击炉子可选中或取消选中，也可以用“全选”和“反选”。选中炉子时，游戏画面会显示临时标记；关闭面板后选择和标记都会清除。点击材料名称选择要补的材料，设置每座炉的目标量，再点“均匀投料”。有燃料且可以点火的锻造炉会开始熔炼。此入口会在存档使用原版熔炼模式时显示。

### 书籍和商人

- 点击网络工具栏的书本按钮可阅读网络里的可读书籍；`Shift` + 左键可批量阅读，右键出售已读书，`Shift` + 右键分解已读书。手动出售或分解得到的东西会放回网络。
- 个人设置可以调整背包书籍的自动处理方式。默认自动阅读开启，已读书会出售，收益放进背包。
- 公爵币按钮可以切换个人手动出售。商人聚合购买和自动买卖规则可从网络界面进入。

### 多人和指令

- 在网络的管理页面邀请玩家、查看成员或进行成员管理。网络管理员可以踢出成员或转让管理员；普通成员可以退出网络。
- 按 `F1` 打开控制台，输入 `hdn-network help`（也可以输入 `sn help`）查看玩家指令。输入时不用加 `/`。服务器管理员可以输入 `hdn-network-admin` 查看维护指令。

## 快捷键和调试

快捷键及日志开关保存在 `HyperdimensionalNetwork.json`：`OpenNetworkKey` 默认是 `O`，`DepositContainerKey` 默认是 `D`，设为 `None` 可以关闭对应快捷键。`DebugLog` 默认关闭。使用工作区的 `sync-to-mods.ps1` 部署时，会为本机 Mods 副本开启调试日志，方便查看问题；仓库里的默认配置仍保持关闭。
