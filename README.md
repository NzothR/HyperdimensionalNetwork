# 超维网络（HyperdimensionalNetwork）

《七日杀》的随身物品存储与物流模组。物品保存在服务端管理的网络中，可在单机使用，也可与其他玩家共享网络。无需解锁物品或 Buff。

## 主要功能

- **存储与取放**：从背包、快捷栏或当前打开的容器快速存入；网络界面支持搜索、分类、分页、拖放和半堆操作。
- **材料供给**：网络中的材料可用于玩家制作、工作站输入、装备维修、建筑修复与升级，以及载具加油和维修。
- **补货与弹药银行**：手动或自动补满快捷栏、背包锁定格中的现有堆叠；远程武器换弹可使用网络弹药。网络管理员可分别开关这两项功能。
- **链式合成**：从已追踪的配方规划材料与依赖，使用原版制作队列或可用工作站执行，并在网络界面查看订单进度。
- **商人交易**：手动出售物品、汇总已发现商人的商品进行购买；网络管理员可设置自动买卖规则。
- **多人共享**：邀请玩家加入网络，管理成员、退出、踢出或转让网络管理员。库存和权限由服务端校验。

## 安装与使用

1. 将模组文件夹放入游戏的 `Mods/HyperdimensionalNetwork`。多人游戏中，主机或服务器及所有客户端都需要安装同一版本。
2. 进入存档后，点击导航栏左侧的书本图标，或按 `O` 打开超维网络。
3. 在网络窗口中存取物品；左键取出一组，右键取出半堆。背包中 `Shift` + 右键可存入半堆，网络中 `Shift` + 右键可取出半堆。
4. 打开箱柜、掉落袋、载具或无人机等物品窗口时，按 `D` 将**当前窗口**中的物品存入网络。此快捷键不会搜索附近容器。
5. 网络窗口的设置入口分为“个人设置”和仅管理员可见的“管理员设置”。个人页可调整自动补货与搜索偏好，管理员页可开关整个网络的补货、弹药银行、商人和合成链功能；自动存入、垃圾桶和书籍阅读的开关也已预留。公爵币按钮用于切换个人手动出售。

快捷键在 `HyperdimensionalNetwork.json` 中设置：`OpenNetworkKey` 默认为 `O`，`DepositContainerKey` 默认为 `D`；设为 `None` 可关闭对应快捷键。`DebugLog` 默认关闭。

玩家可在 F1 控制台输入 `hdn-network help`（别名 `sn help`）查看成员指令，输入命令时无需加 `/`。服务器管理员可输入 `hdn-network-admin` 查看维护指令。

## 开发与状态

在工作区运行 `build.ps1` 构建，运行 `sync-to-mods.ps1` 构建并部署到本机 `Mods`；部署脚本会为本机副本开启 `DebugLog`，仓库默认配置保持关闭。

现有功能已通过单项及多人测试，长时间连续游玩的稳定性仍在观察。自动存入网络、垃圾桶和书籍阅读属于[待评审的功能提案](docs/additional_logistics_features.md)，尚未实现。详细状态见[功能验收状态](docs/acceptance_status.md)，功能规则见[现行设计](docs/design_revised.md)。
