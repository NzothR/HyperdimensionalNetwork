# 超维网络

这是全新模组“超维网络”的工作目录。第一阶段原型已加入，可部署到本机游戏进行单机测试；旧的 `DestroyStorage` 模组保持不变。

## 设计目标

为玩家提供一个随身携带的大型存储网络，并让游戏及已适配的模组把网络中的物品当作玩家可用物品。物品数量查询、精确匹配、预留和消耗都由统一的存储接口处理，避免把海量虚拟物品伪装成普通背包格子。

## 第一阶段原型

- 导航栏左侧书本图标直接打开网络，无需解锁物品或 Buff。
- 从背包和战利品容器一键存入，支持逐格拖放存入/取出、基础分页和分类。
- 物品数量以 `long` 保存；界面及游戏 `ItemStack` 投影最多显示/提供 `int32.MaxValue`。
- 两个开发压力测试物品：按原版堆叠上限加入全部物品变体；以及可堆叠物品每个变体加入 `int32.MaxValue`。
- 游戏配置 `HyperdimensionalNetwork.json` 中 `DebugLog` 默认值为 `false`；本机开发部署配置设为 `true`。

构建：`build.ps1`。部署：`sync-to-mods.ps1`。压力测试可能造成很大的存档日志和明显卡顿，建议在可丢弃的测试存档中使用。

旧模组仅作为现有功能和补丁覆盖面的参考。新模组不承诺兼容旧模组代码或旧存档；目标游戏版本、Harmony/API 接口及常见模组组合需要在实施阶段重新验证。
